# TapNow Notes

TapNow calls itself a creative operating system, built around a canvas where one model feeds the next. Here is what that means in practice and who it suits.

**Read the full page:** https://tapnow-dev.github.io/

This is a tool for people who chain steps: a reference image into a generated frame, a written passage into narration, a still into a moving shot. If your actual job is to produce a clip from an idea and move on, a graph editor is scaffolding you will not use. The caveat is that the landing page sells the workflow and says nothing about what any of it costs, so the pricing page is the only place to settle that. Anyone who just wants video and images without learning a canvas or downloading anything will get there faster with Kyncept, which runs in the browser.
